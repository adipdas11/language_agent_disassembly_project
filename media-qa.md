# Dataset samples and action media

The website includes eight selected samples from the supplied vision training directory:

- RF-DETR-Large: HDD lid, Mini PC internals, Laptop internals.
- RF-DETR-Small: three tool-camera fastener examples.
- YOLOv11-Nano classifier: contact aligned and contact misaligned.

The global and local examples include the original image, supplied polygon annotation masks, and predictions computed with the supplied `checkpoint_best_ema.pth` files at a confidence threshold of 0.4. Class indices follow the zero-based `data.yaml` names. Predictions are generated on CPU and stored as static assets; the website performs no inference.

The classification dataset folders were absent. Its two examples were recovered from the saved image output of cell 2 of `Project 3 (Classification)/yolo11/yolo11-train.ipynb`. The supplied `state_model/best.pt` classifier was run on those images. Notebook source code and credentials are excluded from the website.

Individual source image paths, boxes, and confidence values are recorded in `public/assets/vision/samples.json`. Sources are relative to the supplied vision directory.

## Action clips

| Flip | 00:38.2 | 00:46.0 | 7.8 s |

All clips use the main-camera crop `688:516:0:148`, exported as 960×720 H.264 MP4 at 25 fps with fast-start metadata and no audio. Unscrewing includes a tool-camera inset cropped from `252:188:706:520`. The experiment recording contains accelerated footage; no additional speed change is applied. Crop coordinates and source intervals are retained in `public/assets/actions/clips.json`.

The clips were reviewed using one-frame-per-second contact sheets across their full duration. The extraction clip was shortened after review to exclude the beginning of the next flip action. The flip shows grasping, rotation, and replacement with the PCB facing upwards. The unscrew inset retains the screwdriver engagement and retraction.

## Verification

- Browser checks cover decoding all three clips, progress, looping across the endpoint, pause, and explicit playback under reduced motion.
- Gallery checks cover all three models, sample selection, original/mask/prediction switching, image loading, and classifier-specific controls.
- Responsive checks cover 360, 768, 1280, and 1600 px with no horizontal page overflow.
- Visual screenshots are generated by `node scripts/visual-media-qa.mjs` in `test-results/media-review/`.
- `npm test`, `npx playwright test`, and `npm run build` verify the application.

## Regeneration

`scripts/prepare-research-media.py` accepts the supplied vision directory as its sole argument. It requires Pillow, NumPy, PyYAML, RF-DETR, Ultralytics, and Torch in a separate Python environment. `scripts/prepare-action-clips.py` accepts a local copy of the experiment recording and requires FFmpeg. The full recording and model weights are not bundled with the website.
